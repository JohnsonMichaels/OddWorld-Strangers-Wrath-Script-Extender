WHAT THIS IS
------------
SWSE (the Stranger's Wrath Script Extender) is a small DLL that loads
with the game and powers these mods:

  * SWSE Graphics - a graphics overhaul: sharpening, bloom, filmic
    tonemapping, colour grading, ambient occlusion, optional RTGI, and
    vignette. Only the 3D scene is touched; menus and HUD stay clean.

  * SWSE Console - an in-game command console. Press the ` / ~ key,
    type commands, hit Enter. God mode, ammo, health, transform into
    Steef, music, money, and access to 181 of the game's own functions.

REQUIREMENTS
------------
  * Oddworld: Stranger's Wrath HD (the Steam version).
  * Windows.
  * That's it. No other tools needed.


================================================================
  INSTALLATION  -  step by step
================================================================

STEP 1.  Find your game folder.
   In Steam: right-click Stranger's Wrath -> Manage -> Browse local
   files. A folder opens. This is your GAME FOLDER. It contains a
   "bin" folder and "data" folder. The usual path is:

   C:\Program Files (x86)\Steam\steamapps\common\Stranger's Wrath


STEP 2.  Copy the mod files in.
   From this download, copy these TWO items into your GAME FOLDER:

     - the "bin" folder          (merges with the game's bin folder)
     - the "SWSEMods" folder

   When Windows asks to merge/replace the "bin" folder, say YES -
   it only adds one new file (dinput8.dll), it does not delete anything.


STEP 3.  Run the installer helper (one click).
   In your GAME FOLDER, double-click:

        SWSE-install.bat

   It copies one Windows system file next to the mod so the loader
   works (creates bin\dinput8_real.dll). You only do this once.
   If Windows SmartScreen warns, click "More info" -> "Run anyway"
   (the .bat is plain text - you can open it in Notepad to read it).


STEP 4.  Launch the game (from Steam, normally).
   To confirm it loaded: after you reach the main menu, there will be
   a file  bin\swse_log.txt  in your game folder. If it exists, SWSE
   is running.


STEP 5.  OPTIONAL - HD texture pack (needs the 4GB patch).
   The HD pack (960 textures at 2x) is a separate download because of
   its size. Get it from the project's GitHub Releases page or the
   Discord, then:

   1. Unzip it. You get files ending in .oft
   2. Put them all in:   SWSEMods\SWSE HD\textures
      (create the "textures" folder if it is not there)
   3. Run  SWSE_4GB_Patcher.exe  (included in this download) once.
      WHY: the game is a 32-bit program and Windows only gives it
      2 GB of memory. Measured in a busy scene, the stock game
      already uses 1.7 GB, and the HD textures do not fit in what
      is left - the game would crash on level load. The patcher
      raises the limit to 4 GB. It backs up your exe first, and
      running it with  --restore  puts the original back.
      If your game is under Program Files, right-click it and
      pick "Run as administrator".
   4. Launch the game. To check it worked, open the console
      (~ key) and type:   hd
      It reports how many textures are installed and how many are
      already swapped in. The count rises as levels load.

   Your game files are never modified by the textures themselves:
   delete the .oft files and you are back to vanilla.

   NOTE: Steam's "Verify integrity of game files" replaces the
   patched exe. If HD textures stop working after a verify, run
   SWSE_4GB_Patcher.exe again.


================================================================
  USING THE MODS
================================================================

SWSE GRAPHICS
   * Press  F10  in-game to toggle the graphics effects on/off.
   * Press  F11  to reload settings live after editing them.
   * To tune the look, open in a text editor:
        SWSEMods\SWSE Graphics\settings.txt
     Change a value, save, press F11 in-game. Every effect has a
     comment explaining what it does.

SWSE CONSOLE
   * Press the  ` / ~  key (top-left of the keyboard) to open/close it.
   * Type a command and press Enter.  Esc closes.  Tab autocompletes.
   * The console finds the player on its own. If a command ever says
     it has no player context, pick up any ammo once and retry.
   * Type  help   to see the built-in commands.
   * Type  list <word>   to search all 181 game functions
       e.g.  list music     list npc     list boat
   * Type  call <function> [number]   to run any of them.

   Handy commands:
       god                 toggle invulnerability
       ammo                give all ammo
       heal                full health + stamina
       steef / stranger    transform between forms
       money 50000         set your moolah
       combatmusic 1       force combat music (0 to stop)
       help <command>      details for one command


================================================================
  LOAD ORDER / ENABLING-DISABLING
================================================================
   SWSEMods\load_order.txt controls which mods are on.
     - a line with just the mod name  = enabled
     - put "!" in front of the name   = disabled
     - lines starting with "#"        = comments
   Everything is enabled by default.

   The SWSE DLL's own systems (HD textures, foliage wind, hit
   reactions, graphics, console, AI tuning) are switched on and off
   in  SWSEModseatures.txt  instead - each one can be disabled
   individually, and a disabled system leaves the game completely
   untouched.


================================================================
  UNINSTALL
================================================================
   Delete these from your game folder:
     bin\dinput8.dll
     bin\dinput8_real.dll
     the SWSEMods folder
   The game returns to 100% vanilla. Your saves are never touched.


================================================================
  TROUBLESHOOTING
================================================================
   * No swse_log.txt after launching?  The dinput8.dll files aren't in
     the "bin" folder, or Step 3 wasn't run. Redo Steps 2-3.
   * Console cheats say "no context"?  Pick up ammo once to prime.
   * Graphics look wrong?  Press F10 to toggle off, or edit settings.txt
     and press F11. Set any effect's *_enable to 0 to turn it off.
   * Want vanilla files back?  Steam -> right-click game -> Properties ->
     Installed Files -> Verify integrity of game files.
